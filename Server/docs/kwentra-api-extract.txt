For more info about the guest like email and telephone use the Individual Profile API

1. Overview
This API call retrieves details of a specific Individual Profile in the Kwentra system. An “Individual Profile” usually represents a guest record, containing personal information such as name, nationality, contact details, and identification documents.
In this example, the URL ends with 2, we’re fetching the profile with the internal ID = 2. Which is provided in the name key in Get Reservation API
"name": {
 "id": 2,
 "name": "ahmed monir monir",
 "guest_preferences": "...",
 "first_name": "ahmed",
 "last_name": "monir monir"
 },

2. Example Request

curl --request GET \
 --url 'https://manage.kwentra.com/api/core/individualprofile/v3/2?include%5B%5D=name&include%5B%5D=nationality_object.name&include%5B%5D=email&include%5B%5D=telephone&include%5B%5D=mobile&include%5B%5D=id&include%5B%5D=passport&include%5B%5D=first_name&include%5B%5D=last_name&include%5B%5D=document_type.name&include%5B%5D=issue_date&include%5B%5D=issue_place&include%5B%5D=work_phone&include%5B%5D=driving_license_number&include%5B%5D=old_id&include%5B%5D=ID_number&include%5B%5D=occupation&include%5B%5D=individualprofilecontactinfo_set.city&include%5B%5D=individualprofilecontactinfo_set.country.name&include%5B%5D=guest_preferences&tenant_id=394' \
 --header 'Authorization: Basic VGVzdFVzZXI6VGVzdFVzZXIuMTIz' \
 --header 'accept: application/json, text/plain, */*'
